# 學生版分科測驗落點試算器

這是獨立於老師個案報告的純前端版本。學生輸入的成績只在瀏覽器記憶體內計算，不使用 AI、不呼叫 API、不寫入伺服器，也不使用 `localStorage`。

## 使用方式

直接開啟 `index.html`，或以任一靜態網站伺服器提供此目錄。

## GitHub Pages

此目錄內只有 HTML、CSS 與 JavaScript，可直接作為 GitHub Pages 的發布內容。建議使用獨立公開儲存庫，或只發布此目錄；不要將老師版個案 CSV 一併公開。

## 計算口徑

- 校系資料以114學年度普通生最低錄取分數與採計倍率為主。
- 預設顯示臺大、清大、陽交大、成大、政大、中央、中興、中正、中山、臺師大、彰師大、海大、北大、東吳、長庚及中原共16校。
- 可搜尋並自行加入其他學校；目前收錄52校、495個理工與相關自然科學校系。
- 僅收錄採計科目可由本工具7個成績欄位完整計算的校系；需要歷史、地理、公民、學測數A／數B、社會、自然或術科的校系不列入。
- 差距率＝（學生加權分數－114最低錄取分數）÷114最低錄取分數。
- 夢幻：差距率低於或等於－20％。
- 挑戰：高於－20％、低於或等於0％。
- 穩健：高於0％、低於＋8％。
- 保底：差距率達＋8％以上。
- 採計科目未輸入時，該系組列為資料不足，不硬分區。

歷史最低錄取分數不是錄取保證；正式選填仍須核對當年度招生分則、檢定與名額。
